概述

TTS 源是一个 JSON 对象（或 JSON 数组），描述如何调用在线 TTS API 将文字合成为语音。应用会逐段落发送文本到 API，下载音频并通过 AVAudioEngine 播放。

支持的能力： - GET / POST 请求 - 自定义请求头 - JavaScript 动态构建 URL 和请求体 - 配置界面（选择发音人、风格、API 密钥等） - 响应后处理（解析 JSON 提取 base64 音频等） - 自动故障转移和 API 切换 - Cookie 持久化 - 请求限流 - WebSocket 文本/二进制帧收发

数据结构

{
  "id": 1234567890,
  "name": "源名称",
  "url": "TTS API 地址或 JS 规则",
  "contentType": "audio/mpeg",
  "concurrentRate": "1500",
  "enabledCookieJar": false,
  "loginUrl": "登录/初始化 JS 脚本",
  "loginUi": "配置界面 JSON",
  "loginCheckJs": "响应后处理 JS",
  "header": "{\"Authorization\":\"Bearer xxx\"}",
  "jsLib": "公共 JS 函数库",
  "lastUpdateTime": 1700000000000,
  "enabled": true
}

字段说明

字段 类型 必填 说明
id Int64 否 唯一数字 ID。缺失时由 name 的 hash 自动生成
name String 是 源显示名称
url String 是 TTS 请求地址（支持 JS 规则）
contentType String 否 响应 Content-Type 验证正则，如 audio/(mpeg\|wav)
concurrentRate String 否 请求限流，单位毫秒（如 "1500" 表示间隔 1.5 秒）
enabledCookieJar Bool 否 是否启用 Cookie 持久化，默认 false
loginUrl String 否 JS 脚本，在配置界面按钮点击时执行
loginUi String 否 配置界面定义（JSON 数组或 @js: 动态生成）
loginCheckJs String 否 每次 HTTP 响应后执行的 JS，可修改/替换响应
header String 否 JSON 格式的自定义请求头
jsLib String 否 公共 JS 函数库，在所有 JS 执行前预加载
lastUpdateTime Number 否 最后更新时间戳（毫秒）
enabled Bool 否 是否启用

URL 规则

url 是最核心的字段，定义如何构建 TTS 请求。

可用变量

变量 说明
{{speakText}} 待朗读的文本（在 URL 部分自动 URL 编码，在 JSON body 中自动 JSON 转义）
{{speakSpeed}} 语速值，整数 1-30，默认 10 为正常速度。由 speechRate × 10 计算
speakText JS 中可用的全局变量（原始文本，不编码）
speakSpeed JS 中可用的全局变量（整数）

语速换算：应用的 speechRate 范围 0.1~3.0，换算为 speakSpeed = Int(speechRate × 10)，即 1~30，10 为正常。 例如 speechRate=1.5 → speakSpeed=15

方式一：简单 GET 请求

直接使用模板替换：

https://api.example.com/tts?text={{speakText}}&speed={{speakSpeed}}&voice=xiaoxiao

{{speakText}} 自动 URL 编码，安全处理特殊字符。

方式二：POST 请求（@body 方式）

在 URL 和 body 之间使用 , 分隔，body 部分为 JSON 配置：

https://api.example.com/tts,{"method":"POST","body":"{\"text\":\"{{speakText}}\",\"speed\":{{speakSpeed}}}","headers":{"Content-Type":"application/json"}}

body 中的 {{speakText}} 会自动 JSON 转义（处理换行、引号等）。

方式三：JavaScript 规则

使用 @js: 前缀编写完整的 JS 逻辑：

@js:
var info = source.getLoginInfoMap();
var voice = info['voice'] || 'xiaoxiao';
var speed = (speakSpeed - 10) * 10;  // 转换为 -90 ~ +200 范围
var text = encodeURIComponent(speakText);
`https://api.example.com/tts?text=${text}&voice=${voice}&rate=${speed}%`

注意：JS 规则的最后一个表达式的值（或 return 值）就是最终的 URL。

JavaScript URL 中构建 POST 请求

JS 规则返回的字符串也支持 ,{JSON配置} 格式：

@js:
var body = JSON.stringify({
    text: speakText,
    speed: speakSpeed
});
// 返回 URL + POST 配置
`https://api.example.com/tts,{"method":"POST","body":${JSON.stringify(body)},"headers":{"Content-Type":"application/json"}}`

URL 中的 JS 表达式

在模板占位符 {{...}} 中可以写 JS 表达式：

https://api.example.com/tts?speed={{speakSpeed * 4}}%&text={{speakText}}

loginUi 配置界面

loginUi 定义一个 JSON 数组，每个元素表示一个 UI 控件。用户选择的值保存到 loginInfo，可在 JS 中通过 source.getLoginInfoMap() 访问。

支持的控件类型

select（下拉选择）

{
  "name": "voice",
  "type": "select",
  "viewName": "'发音人：'",
  "chars": ["晓晓", "云溪", "晓梦", "云扬"],
  "default": "晓晓",
  "action": "onVoiceChange()",
  "style": { "layout_flexGrow": 1, "layout_flexBasisPercent": 0.4 }
}
  • name：保存到 loginInfo 的 key
  • chars：选项列表
  • default：默认选中值（首次使用时自动保存）
  • action：选择变更时执行的 JS 函数（可选，在 loginUrl 中定义）
  • viewName：显示标签

text（文本输入）

{
  "name": "apiKey",
  "type": "text",
  "viewName": "'API Key：'",
  "chars": ["请输入你的API密钥"]
}
  • chars[0]：输入框的占位符提示文字
  • 用户输入保存到 loginInfo 的对应 key

toggle（切换开关）

{
  "name": "autoCleanCache",
  "type": "toggle",
  "viewName": "'自动清理缓存'",
  "chars": ["✅", "🔳"],
  "default": "✅"
}
  • chars[0]：开启状态显示
  • chars[1]：关闭状态显示
  • 值在两个状态之间切换

button（操作按钮）

{
  "name": "测试接口",
  "type": "button",
  "action": "testApi()",
  "style": { "layout_flexBasisPercent": 0.5 }
}
  • 不保存值，点击执行 action 中的 JS 代码
  • JS 在 loginUrl 脚本的上下文中执行
  • 可用 java.toast() 显示结果

动态生成 loginUi

loginUi 支持 @js: 前缀，动态生成 JSON 字符串：

@js:
var voices = {"晓晓":"XiaoxiaoNeural","云溪":"YunxiNeural"};
var voiceList = Object.keys(voices).map(k => `"${k}"`).join(',');
`[
  {"name":"voice","type":"select","viewName":"'发音人：'","chars":[${voiceList}]},
  {"name":"style","type":"select","chars":["无风格","欢快","严肃","温柔"]},
  {"name":"查看配置","type":"button","action":"showConfig()"}
]`

style 布局属性

属性 说明
layout_flexGrow flex 增长因子（0=不扩展）
layout_flexBasisPercent 占行宽百分比（0~1，如 0.4 表示 40%）
layout_wrapBefore 是否在此控件前换行 (true/false)

loginUrl 登录脚本

loginUrl 是一段 JS 代码，在以下时机执行： 1. 按钮点击：loginUi 中 type: "button" 的 action 调用的函数定义在这里 2. select/toggle 变更：带 action 的选择控件变更时执行

执行上下文

  • result：当前 loginUi 中所有控件的值（对象形式 {name: value, ...}）
  • source：源对象（可读写持久化数据）
  • java：JS 桥接对象（网络请求、工具函数等）
  • jsLib 中定义的所有全局变量和函数

典型用法

// 定义函数，供 loginUi 按钮调用
function testApi() {
    var api = result["api"];
    var res = java.ajaxTestAll([api + "?test=1"], 3000, true);
    var time = res[0].callTime();
    if (time > 0) {
        java.toast("接口正常，延迟：" + time + "ms");
    } else {
        java.toast("接口无法访问！");
    }
}

function onVoiceChange() {
    // 切换发音人时清理音频缓存
    if (result["autoCleanCache"] === "✅") {
        java.clearTtsCache();
    }
}

loginCheckJs 响应处理

loginCheckJs 在每次 HTTP 请求返回后执行，可用于： - 验证响应状态 - 从 JSON 响应中提取音频数据 - 故障转移（切换 API 重新请求） - 修改持久化配置

可用对象

result（HTTP 响应对象）

result.code()                    // HTTP 状态码（如 200、403、500）
result.body().string()           // 响应体字符串
result.body().bytes()            // 响应体字符串（兼容用法）
result.headers()                 // 响应头对象 {key: value}
result.header('Content-Type')    // 获取单个响应头（不区分大小写）

java 桥接对象

java.getResponse()               // 重新发送 HTTP 请求，返回新的 result
java.initUrl()                   // 重新解析 URL 规则（修改 loginInfo 后调用）
java.setResponseBase64(base64Str, contentType)  // 将 base64 解码并替换响应数据
java.ajax(url)                   // 同步 GET 请求
java.toast(msg)                  // 显示 Toast 提示
java.log(msg)                    // 调试日志

场景一：直接返回音频流

如果 API 直接返回音频二进制数据，不需要 loginCheckJs。

场景二：从 JSON 响应提取 base64 音频

if (result.code() == 200) {
    var body = result.body().string();
    var json = JSON.parse(body);
    // 假设 API 返回 {"audio": "base64编码的音频数据"}
    var audioBase64 = json.audio;
    java.setResponseBase64(audioBase64, 'audio/wav');
}
result

java.setResponseBase64(base64, contentType) 会将 base64 解码为二进制数据，替换原响应。

场景三：API 故障转移

if (result.code() != 200) {
    java.toast("接口失效，正在切换...");

    // 获取备用 API 列表
    var apis = ["http://api1.com/tts", "http://api2.com/tts"];
    var testUrls = apis.map(a => a + "?t=test&v=default");
    var results = java.ajaxTestAll(testUrls, 3000, true);

    // 找到延迟最低的 API
    var bestIdx = -1, bestTime = 99999;
    for (var i = 0; i < results.length; i++) {
        var time = results[i].callTime();
        if (time > 0 && time < bestTime) {
            bestIdx = i;
            bestTime = time;
        }
    }

    if (bestIdx >= 0) {
        // 保存最优 API 并重试
        var info = source.getLoginInfoMap();
        info['api'] = apis[bestIdx];
        source.putLoginInfo(JSON.stringify(info));
        java.initUrl();                // 重新解析 URL（使用新的 loginInfo）
        result = java.getResponse();   // 重新发送请求
    }
}
result  // 必须返回 result 对象

重要：loginCheckJs 最后一行必须返回 result 对象。

jsLib 公共函数库

jsLib 中的代码在 loginUrl、loginCheckJs、url（JS 规则）执行之前预加载，适合放置： - 共享常量（发音人映射表、API 列表等） - 共享函数

var voices = {
    "晓晓": "zh-CN-XiaoxiaoNeural",
    "云溪": "zh-CN-YunxiNeural",
    "云扬": "zh-CN-YunyangNeural"
};

var styles = {
    "无风格": "",
    "欢快": "cheerful",
    "严肃": "serious",
    "温柔": "gentle"
};

function buildTtsUrl(text, speed, apiBase) {
    var info = source.getLoginInfoMap();
    var voice = voices[info['voice']] || "zh-CN-XiaoxiaoNeural";
    var style = styles[info['style']] || "";
    var rate = (speed - 10) * 10;  // speakSpeed 10=正常 → rate 0%
    return `${apiBase}?t=${encodeURIComponent(text)}&v=${voice}&r=${rate}%&s=${style}`;
}

注意：jsLib 中的 let/const 声明会自动转换为 var，避免重复声明错误。

WebSocket 朗读源

JavaScriptCore 本身没有浏览器的 WebSocket 对象。TTS 源可以在 URL 的 JS 规则中调用 java.webSocket(config)：原生层负责连接和帧收发，握手消息、协议状态和音频提取仍由可导入源的 jsLib 定义。

// url
@js:java.webSocket(makeSession(speakText, speakSpeed))

// jsLib
function makeSession(text, speed) {
    return {
        url: "wss://speech.example.com/tts",
        headers: {"Authorization": "Bearer token"},
        send: [JSON.stringify({text: text, speed: speed})],
        onMessage: handleFrame,
        connectTimeout: 12000,
        receiveTimeout: 30000,
        maxAudioBytes: 16777216,
        contentType: "audio/mpeg"
    };
}

function handleFrame(message, state) {
    if (message.type === "text") {
        var value = JSON.parse(message.text);
        if (value.error) return {error: value.error};
        if (value.done) return {done: true};
        return value.audio ? {audio: value.audio} : null;
    }
    var headerLength = message.uint16BE(0);
    return {audio: message.base64(2 + headerLength, -1)};
}
配置字段必填说明
url是ws:// 或 wss:// 地址
headers否WebSocket 握手请求头
send是初始消息数组；字符串为文本帧，{type:"binary",data:"Base64"} 为二进制帧
onMessage是jsLib 函数或 JS 表达式字符串
connectTimeout否建连超时，毫秒，默认 12000
receiveTimeout否单帧等待超时，毫秒，默认 30000
maxAudioBytes否单段音频上限，默认 16 MiB，最大 64 MiB
contentType否音频类型，默认 audio/mpeg

二进制帧通过 message.count、message.byteAt(offset)、message.uint16BE(offset)、message.utf8(offset,length) 和 message.base64(offset,length) 按需读取，length=-1 表示读取到末尾。

onMessage 可返回 audio（Base64 音频）、send（后续帧）、state（下一帧状态）、done 或 error。返回 null/undefined 表示忽略当前帧。完整 Edge 示例见 源/大声朗读.json。

首次使用自动初始化

应用首次选中 TTS 源时，会自动解析 loginUi，将 select 和 toggle 控件的 default 值保存到 loginInfo，确保后续使用时不为空。

请求限流

concurrentRate 控制请求间隔，防止过快请求导致 API 封禁：

"concurrentRate": "1500"     // 每个请求间隔 1500ms
"concurrentRate": "1/1000"   // 每 1000ms 允许 1 个请求
"concurrentRate": "0"        // 不限流
"concurrentRate": ""         // 不限流

建议设置合理的限流，大多数 TTS API 建议 1000~2000ms 间隔。

音频格式

contentType 验证

contentType 是正则表达式，用于验证 HTTP 响应的 Content-Type。不匹配则视为请求失败。

"contentType": "audio/mpeg"                    // 精确匹配 MP3
"contentType": "audio/(mpeg|mp3|wav|ogg)"      // 匹配多种格式
"contentType": "audio/.*"                      // 匹配所有音频类型
"contentType": ""                              // 不验证（使用默认逻辑）

默认行为（contentType 为空时）： - 拒绝 text/html 和 application/json（视为错误页面/非音频响应） - 接受其他所有 Content-Type

特殊情况：如果 API 返回 JSON（含 base64 音频），需要在 loginCheckJs 中用 java.setResponseBase64() 转换后，contentType 设为 "audio/.*" 即可。

支持的音频编码

应用使用 AVAudioEngine 解码音频，支持所有 Apple 平台原生格式：

  • MP3 (audio/mpeg)
  • WAV (audio/wav)
  • AAC (audio/aac)
  • FLAC (audio/flac)
  • M4A (audio/mp4)
  • OGG (audio/ogg)

所有格式统一转换为 Float32 单声道 PCM 后播放。

调试技巧

1. 使用 java.log() 输出调试信息

在 JS 代码中插入 java.log() 输出变量值，可在应用的 JS 控制台面板中查看：

java.log("当前API: " + source.getLoginInfoMap()['api']);
java.log("speakSpeed: " + speakSpeed);
java.log("响应状态码: " + result.code());
java.log("响应头: " + JSON.stringify(result.headers()));

2. 使用 java.toast() 快速验证

在 loginUrl 的按钮动作中使用 toast 快速查看状态：

function showConfig() {
    var info = source.getLoginInfoMap();
    java.toast(JSON.stringify(info, null, 2));
}

4. 常见问题排查

现象 可能原因 解决方案
无声音输出 contentType 不匹配 检查 API 实际返回的 Content-Type，调整正则
提示"不支持的音频格式" API 返回 HTML 错误页 添加 loginCheckJs 检查 result.code()
loginInfo 读取为空 首次使用未设默认值 在 loginUi 中设置 default 字段
API Key 未传递 请求头未正确注入 使用 source.putLoginHeader(JSON.stringify({...}))
速度调节无效 未使用 speakSpeed 变量 在 URL 中使用 {{speakSpeed}} 或 JS 中读取 speakSpeed
JS 报错 let/const 重复声明 jsLib 中用 var（系统会自动转换，但最好主动使用 var）
Cookie 丢失 未启用 Cookie 持久化 设置 "enabledCookieJar": true
